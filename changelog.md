# Changelog

## v1.0

- Initial release of Sub-GHz Editor
- File browser integration for opening `.sub` captures directly from SD card (`/ext/subghz`)
- Standard frequency presets cycling (315.00, 318.00, 345.00, 390.00, 433.07, 433.88, 433.92, 434.42, 434.77, 868.35, 868.85, 915.00 MHz)
- Manual frequency input with hardware band safety checks (CC1101 supported bands)
- Interactive hexadecimal key code payload editor
- Safe file saving: in-place overwrite or Save As Copy (`_edit.sub`)
- File manager association and direct launch with `.sub` argument
